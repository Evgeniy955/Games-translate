# Games Translate

Українські локалізації ігор та готові інсталятори для їх встановлення.

## Assetto Corsa Rally

Українська локалізація меню, налаштувань, режимів гри та ралійної термінології для **Assetto Corsa Rally**.

Актуальний інсталятор розміщено в каталозі [`AssettoCorsaRally`](./AssettoCorsaRally/). Він автоматично знаходить бібліотеку Steam, перевіряє сумісність версії гри, створює резервну копію оригінального PAK і дозволяє відновити оригінальні файли.

## Assetto Corsa EVO

Українська локалізація інтерфейсу, підказок, налаштувань і характеристик автомобілів для **Assetto Corsa EVO**.

Інсталятор для сумісної версії гри та інструкції з установлення доступні в каталозі [`AssettoCorsaEVO`](./AssettoCorsaEVO/). Вбудована перевірка оновлень отримує список інсталяторів безпосередньо з цієї папки GitHub.
