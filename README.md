## Le Mans Ultimate

Українська локалізація меню, налаштувань, HUD і гоночної термінології для **Le Mans Ultimate**.

Актуальний інсталятор розміщено в каталозі [`LMU`](./LMU/). Він автоматично перевіряє сумісність файлів гри, створює резервну копію оригіналів і дозволяє відновити їх за потреби.

### Встановлення

1. Завантажте останній файл `LMU-UA-Launcher-*.exe` із каталогу `LMU`.
2. Закрийте гру та запустіть інсталятор.
3. Перевірте шлях до папки **Le Mans Ultimate** і встановіть переклад.
4. У властивостях гри в Steam виберіть мову **Polish** — цей мовний слот використовується для української локалізації.

Якщо після оновлення гри виникли проблеми, відновіть оригінальні файли через інсталятор або перевірте їх у Steam: **Властивості → Встановлені файли → Перевірити цілісність файлів гри**.

> Це неофіційний переклад, створений для української спільноти LMU.

## Assetto Corsa Rally

Українська локалізація меню, налаштувань, режимів гри та ралійної термінології для **Assetto Corsa Rally**.

Актуальний інсталятор розміщено в каталозі [`AssettoCorsaRally`](./AssettoCorsaRally/). Він автоматично знаходить бібліотеку Steam, перевіряє сумісність версії гри, створює резервну копію оригінального PAK і дозволяє відновити оригінальні файли.
