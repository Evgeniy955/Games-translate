## Встановлення

1. Завантажте EXE-файл і закрийте гру.
2. Запустіть інсталятор.
3. Перевірте автоматично знайдену папку Assetto Corsa Rally або виберіть її вручну.
4. Натисніть **«ВСТАНОВИТИ ПЕРЕКЛАД»**.

Інсталятор створює резервну копію оригінального PAK. Кнопка **«ВІДНОВИТИ ОРИГІНАЛ»** повертає оригінальні файли та англійську мову.
